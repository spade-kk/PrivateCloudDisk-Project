                       │ 互补

│  "控制谁能做什么"                                               │
│  download_grant.py  → 下载授权 + 分块并发控制                    │
│  rate_limiter.py    → 每 Token 的请求次数/速率/并发              │
│  GatewayRateLimitFilter → 登录/注册/上传频次策略                 │
│  ApiAbuseProtectionService → 登录失败锁定/注册频率               │
└──────────────────────────────────────────────────────────────┘

```
攻击场景                          防护层                       效果
────────────────────────────────────────────────────────────────────
热门文件爆发性下载 →   网关/业务请求策略                 按部署侧阈值触发
                     + download_grant 分块并发控制     每 Token 最多 4 并发块

恶意批量删除 POST    →  网关/业务请求策略                 按部署侧阈值触发
  /files/delete      + 业务接口权限校验                   按策略执行
                     + ApiAbuseProtectionService        业务滥用检测

大量并发上传撑爆线程池 → 网关/存储服务请求策略             按部署侧阈值触发
                     + 上传并发控制                       按配置执行
                     + 系统保护策略                       按监控策略执行

下游服务异常拖慢网关  →  网关熔断降级策略                   按监控策略执行
                     + GatewayRateLimitFilter           业务策略继续生效

用户疯狂注册/登录    →  GatewayRateLimitFilter           IP/指纹维度限流
                     + ApiAbuseProtectionService        登录失败锁定
```
